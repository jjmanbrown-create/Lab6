# Lab 6 – Java Programming Projects

This repository contains three Java programming projects completed as part of CISC 230 (Object-Oriented Design and Programming) at the University of St. Thomas. Each task demonstrates different programming concepts through interactive applications.

## Task 1: Campus Library Management System
Developed a library management system that reads book information from a file and allows users to manage library resources.

**Features:**
- Search for books and view library information.
- Borrow and return books.
- Manage book availability.
- Complete missions and earn points through an integrated mission system.

## Task 2: Vowel Finder Game
Created an interactive vowel-finding game that reads words from a file and allows users to choose between different difficulty levels.

**Features:**
- Multiple difficulty levels based on word length.
- Identify vowels at specific character positions.
- Track game progression and points.
- Earn bonus points and receive hints about word length.

## Task 3: Interactive Shape Designer
Designed an interactive application that allows users to create circles and rectangles by entering specific dimensions.

**Features:**
- Select between circles and rectangles.
- Enter and validate shape dimensions.
- Calculate total area and perimeter or circumference.
- Toggle grid lines and hide or display calculated results.
